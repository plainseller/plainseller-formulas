# PlainSeller formulas

PlainSeller (https://plainseller.com) offers free calculators and tools for online sellers, freelancers and small businesses.

This page lists the plain formulas used by the calculators, so you can check them yourself.

## Pricing

- Markup % = (price - cost) / cost x 100
- Profit margin % = (price - cost) / price x 100
- Price from cost and markup = cost x (1 + markup / 100)

## Hours and pay

- Time to decimal = hours + minutes / 60
- Overtime pay = hours x rate x multiplier
